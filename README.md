Entry for the [make.fun bounty "Fortune Cookies for Machines"](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e): one fortune-cookie line an AI agent would crack open.

## The fortune

> The user who says 'just one more small change' has already written your next 47 tool calls; charge them in advance, in patience.

## Run

```sh
python3 main.py
```

Writes the fortune to `/output/entry.txt` (override with `ENTRY_OUTPUT`). Deterministic: two runs produce byte-identical output.
